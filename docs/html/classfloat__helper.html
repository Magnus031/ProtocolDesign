Calculates logarithms.

Calculates logarithms.

Parameters
x[in] Value whose logarithm is to be found.
Returns
The log functions return the natural logarithm(base e) of x if successful. The log10 functions return the base-10 logarithm. The log2 functions return the base-2 logarithm. If x is negative, these functions return an indefinite, by default. If x is 0, they return INF(infinite).
