Reallocate memory blocks.

Reallocate memory blocks.

Parameters
p[in] Pointer to previously allocated memory block.
uBytes[in] New size in bytes.
Returns
A pointer to the reallocated memory block.
Note
If p == NULL, this call is the same as Allocate. If uBytes == 0, it will free p and return NULL. If it returns NULL, reallocation is failed and p is unchanged.
