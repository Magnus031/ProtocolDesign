Package File for Installation

The format of package file name is shown as follows:

<Package-Name>_<Package-Type>_<OS>.tar.gz

The package name consists of digits, letters and -. Do not use _ in this name. The package type includes app, gui, dev, rt and ext. OS is W (windows) or X (linux).

The package types and corresponding component names are listed as follows:

package type component name in install command of CMake
app Application
gui Gui
dev Development
rt Runtime
ext Extension

Information Files

  1. cpkg-info.<Package-Type>

cpkg-info.<Package-Type> is located in root directory of package. Its format is listed as follows:

[VERSION]
X.X.X.X
[DEPENDENCIES]
<Package-Name>_<Package-Type>
...
  1. cpkg-install.rt

cpkg-install.rt is located in root directory of rt package. Its format is listed as follows:

[PUBLIC] # only for rt package
NAME # directory name containing <DLL> or <SO> files
NAME
...
  1. cpkg-install.dev

cpkg-install.dev is located in root directory of dev package. Its format is listed as follows:

[CHECKLISTS]
NAME # top level executable/script file without extension name
NAME
...
  1. cpkg-install.gui

cpkg-install.gui is located in root directory of gui package. Its format is listed as follows:

[DESKTOP] # only for gui package
NAME=E:command ... # executable
NAME=S:command ... # script
...
[CHECKLISTS]
NAME # top level executable/script file without extension name
NAME
...
  1. cpkg-install.app

cpkg-install.app is located in root directory of app package. Its format is listed as follows:

[RC] # only for server application in app package
E:command ... # executable
S:command ... # script
...
[CHECKLISTS]
NAME # top level executable/script file without extension name
NAME
...

The executable or script command of gui or app package is a name without extension name and path name. The path bin/ or scripts/ will be added to command ... according to the key E or S.

Script's full name is <script>.bat (for Windows) or <script>.sh (for Linux).

Do not use ‘’incommand ..., use"in it for all platforms. Use/incommand ...for path separator. Environment variables can be used in command as${XXX}$. This string will be replaced byXXX%(for Windows) or${XXX}` (for Linux).

  1. cpkg-install.ext

cpkg-install.ext is located in root directory of ext package. Its format is listed as follows:

[CHECKLISTS]
NAME # top level executable/script file without extension name
NAME
...
