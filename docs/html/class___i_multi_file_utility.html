Detailed Description

An interface for utility of multi-file stream.

An interface for utility of multi-file stream.

Note
A multi-file stream is located in a directory. The format of file names is 'MFXXXXYYYYYY'. 'XXXX' specifies the maximum size of file (MB) within [1, 2000]. 'YYYYYY' specifies the index of a serial of files.
