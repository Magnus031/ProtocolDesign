Detailed Description

A class for state machine.

A class for state machine.

Note
In class FSA_TABLE, user must define enumerations of states (from 2 to nMaxStateNo), stop states (0 or the match index of states must be <= 0), events (from 0 to nMaxEventNo) and matches (from 1 to nMaxMatchNo). The state map and match map should also be defined.
