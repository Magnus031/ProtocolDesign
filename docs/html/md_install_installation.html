Install

Install GDAM (GKC-Development Application Management System) on machines of client end or server end for production and running infrastructure. Uncompress the package file generated by cpack, and run setup script with specified parameters to install the package.

  • Windows

    Run the following command as administrator:

    ``` setup.bat <user-name> <password> <package-root directory> <data directory> ```

    <user-name> and <password> of Administrator are used to generate a task scheduler. Some environment variables will be generated in ProgramData%\GDAM\vars.bat.

  • Linux

    ``` sudo bash setup.sh <package-root directory> <data directory> ```

    Some environment variables will be generated in /etc/GDAM/vars.sh.

<package-root directory> specifies the root directory for packages. Entry directories are listed as follows:

folder description
app Application packages
gui Gui packages
dev Development packages
rt Runtime packages
ext Extension packages
cache Package cache
download Downloaded packages
temp Temporary directories/files

<data directory> specifies the entry directory for data. The network shared directory can also be used as data directory. The entry directories work and temp are created under <data directory>. The entry directories public, groups and users are created under work and temp. The entry directories sys and pkg are created under public.

The recommendation for <package-root directory> and <data directory> is listed as follows:

Folder Windows Linux
<package-root directory> D:\opt\cpkg /opt/cpkg
<data directory> E:\cpdata /home/cpdata

Uninstall

  • Windows

    Run the following command as administrator:

    ``` "%ProgramData%\GDAM\uninstall.bat" [-f] ```

  • Linux

    ``` sudo bash /etc/GDAM/uninstall.sh [-f] ```

-f means execute the uninstall script regardless of whether the executable files or shared libraries are in use or not.

Usage

Run ProgramData%\GDAM\vars.bat or /etc/GDAM/vars.sh to use tools of GDAM and develop user projects.
