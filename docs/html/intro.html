Introduction

GKC (General Kind C++) is a basic cross-platform C++ programming library. GKC library can be used on Windows and Linux.

Layers

The programming of GKC consists of two layers, System and User. The System layer is lower and the User layer is higher. The classes and functions of System layer can not use APIs from User layer, but those of User layer can use APIs from System layer.

The System layer provides classes and functions related to OS using format xxx_xxx.

The User layer can be further divided to two sublayers, Runtime and Application. The classes and functions of each sublayer can use APIs from all sublayers.

  • Runtime

Provide classes and functions implemented in SA (Shared Assembly, i.e., DLL/SO) with format _XxxXxx. The classes and functions in layers System, Runtime and Application can be used to implement SA.

  • Application

Provide classes and functions for programmers with format XxxXxx.
