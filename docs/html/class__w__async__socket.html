BOOL _w_async_socket::Create ( int  af,

)
inlinenoexcept

Create a socket.

Create a socket.

Parameters
af[in] The address family specification. See AF_*.
st[in] The type specification for the new socket. See SOCK_*.
proto[in] The protocol to be used. It can be 0, see IPPROTO_*.
dwFlags[in] A flag that specifies the socket attribute.
Returns
TRUE for succeeded, FALSE for failed.
Note
To create a raw socket, call Create(AF_INET, SOCK_RAW, IPPROTO_IP [or IPPROTO_RAW], 0), set a BOOL variable bFlag to TRUE, then call SetSockOpt(IP_HDRINCL, &bFlag, sizeof(BOOL), IPPROTO_IP), and call Bind() with local host address and specified port optionally. If the raw socket is bound to an interface, use Read() and Write() to process data IO. Otherwise, use ReadFrom() and WriteTo() to process data IO. To receive all packets, set a DWORD variable dwValue to 1, and call Ioctl(SIO_RCVALL, &dwValue, sizeof(DWORD), ...). If dwValue is set to 0, it means all packets would not be received.
